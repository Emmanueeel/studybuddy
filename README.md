# 🎓 StudyBuddy

**StudyBuddy** — это микросервисное веб-приложение для поиска напарников среди студентов. Система анализирует навыки, дисциплины и расписание, чтобы подобрать идеальную команду для учебы, курсовых или хакатонов.

## 🚀 Технологический стек
* **Backend:** Go (Golang), REST API, JWT, Goroutines (для параллельного скоринга)
* **Frontend:** HTML5, JavaScript (Fetch API), Tailwind CSS (CDN)
* **Базы данных:** PostgreSQL (Database-per-service)
* **Инфраструктура:** Docker, Docker Compose
* **Брокер сообщений:** RabbitMQ (событийно-ориентированная архитектура)
* **Кэширование:** Redis

## 🏗 Архитектура
Проект построен по принципам микросервисной архитектуры и включает в себя 6 независимых сервисов:
1. **API Gateway** (порт 8080) — маршрутизация, проверка JWT, CORS.
2. **Auth Service** (8081) — регистрация, авторизация, выдача токенов.
3. **Profile Service** (8082) — управление профилями, обновление рейтинга.
4. **Matching Service** (8083) — ядро системы, алгоритм подбора с параллельным скорингом.
5. **Request Service** (8084) — создание и управление заявками.
6. **Review Service** (8085) — система отзывов.

*Взаимодействие сервисов осуществляется как синхронно (HTTP), так и асинхронно (через RabbitMQ для обновления рейтингов).*

## 📦 Быстрый запуск

Для запуска всего проекта (базы данных, брокеры и 6 микросервисов) вам понадобятся установленные **Docker** и **Docker Desktop**.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/studybuddy.git
   cd studybuddy

2. Запустите всю инфраструктуру и сервисы одной командой:
        ```bash
    docker compose up -d --build

3. Откройте frontend/index.html через расширение Live Server в VS Code

✨ Ключевые особенности
Умный матчинг: Алгоритм рассчитывает score совпадения на основе общих навыков, дисциплин, свободного времени и текущего рейтинга пользователя.

Идемпотентность: Создание заявок защищено от дублирования при повторных запросах (заголовок Idempotency-Key).

Событийная шина: После завершения заявки и оставления отзыва, рейтинг пользователя обновляется автоматически через RabbitMQ без прямого вызова сервисов.

Масштабируемость: Использование горутин в Go позволяет обрабатывать сотни профилей кандидатов за миллисекунды.
